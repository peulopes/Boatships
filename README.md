# Boatships

A Unity project for boat and ship gameplay experiments. Just a sandbox to learn about unity, C# scripts, blender and game design.

## Getting started
- Requirements
  - Unity Hub installed
  - Unity Editor version matching ProjectSettings/ProjectVersion.txt
  - Git (to clone the repository)
- Clone
  - git clone https://github.com/peulopes/Boatships.git
- Open
  - Open Unity Hub
  - Add the project folder and open it with the Editor version from ProjectVersion.txt

## Play and iterate
- Open the project in Unity
- Use the Project window to locate scenes (Assets/**/Scenes)
- Press Play to run in the Editor
- Use the Console (Window > General > Console) to inspect logs and errors

## Build
- File > Build Settings
- Select target platform, Add Open Scenes (or add required scenes)
- Player Settings to configure company/product identifiers and icons
- Click Build (or Build And Run)

## Project structure
- Assets/           Your game content: scenes, scripts, prefabs, materials, etc.
- Packages/         Package manifest and lock file for dependencies
- ProjectSettings/  Unity project configuration
- UserSettings/     Local user settings (not for CI)
- Library/          Generated by Unity (do not commit)

## Development tips
- Use the Unity Console to track compilation errors and warnings
- Maintain consistent .meta files by committing the entire Assets/ and Packages/ folders
- After pulling changes, let Unity re-import assets before pressing Play
